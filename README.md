# A 股复盘看板

一个本地优先的 A 股涨停与连板复盘看板。导入板块矩阵 Excel 后，可按日期、板数和题材整理个股，并在本机保存复盘备注、题材归类、排序和行情补充数据。

> 本项目不包含任何人的 API Key、账号凭据、私人复盘数据或第三方页面快照。

## 功能

- 导入 `.xls` HTML 导出表或 `.xlsx` 板块矩阵，同日更新保留本地个人设置。
- 显示 1–7 个交易日；单日模式左侧首板、右侧二板及以上。
- 首板按题材分组，支持题材排序、合并、手动归类、撤销和未归类保留。
- 二板及以上展示个股、多题材、省份和当日备注。
- 题材近15交易日高度天梯，每日最高板折线、板数分布和完整股票名单。
- 题材/省份连板历史，同首板日成批，全部断板后记录该批最高板。
- 板数、个股、题材和每日复盘富文本备注，支持换行、粗体、斜体、下划线、字号和字色。
- 当日首板个股同时属于 2 个及以有效题材时，股名显示为橙色；二板及以上不变色。
- 问财行情补充：自由流通占比、自由流通市值、收盘价、首次/最后涨停时间、成交额、封成比和省份。
- “今日反包”查询、长图导出、个股颜色标记和省份联动高亮。

## 数据来源与边界

### 连板天梯 / 板块矩阵

本项目使用者自行取得的 **短线侠“连板天梯”**板块矩阵 Excel 作为基础输入，读取其交易日、题材、股票名单和板数。

本项目不自动登录短线侠，不内置短线侠的账号、Cookie 或私有接口，也不提供绕过访问权限的抓取功能。请使用你有权获取的文件，并遵守上游平台条款。

### 个股行情

个股行情和“今日反包”数据来自 **同花顺问财** OpenAPI。每位使用者必须使用自己账号下的 Key。

本项目与短线侠、同花顺问财无隶属、代理或授权关系。仓库中的代码和说明不构成投资建议。

## 安装与启动

### macOS

1. 安装 Python 3.10 或更新版本。
2. 下载本仓库。
3. 双击 `启动复盘看板.command`，或在终端运行：

```bash
python3 server.py --open
```

### Windows / Linux

```bash
python3 server.py --open
```

默认地址：[http://127.0.0.1:8765](http://127.0.0.1:8765)。服务只监听本机回环地址。

首次启动时没有任何内置复盘数据。点击右上角 `＋` 导入你自己的 Excel。数据会在首次保存时自动写入本机 `data/state.json`；`data/` 已被 Git 忽略。

## 如何获取自己的问财 Key

1. 打开 [同花顺问财 SkillHub](https://www.iwencai.com/skillhub) 并登录你自己的账号。
2. 在 SkillHub 搜索并打开 **问财选 A 股** / `hithink-astock-selector` 技能。
3. 在“安装方式”中选择 **Agent 用户** 或 **CLI 用户**。
4. 找到属于你自己账号的 `IWENCAI_API_KEY`。
5. 在看板的“数据设置”中粘贴 Key。Key 只保留在当前服务进程内，不写入前端、源码或 `data/state.json`。

也可以在启动前设置环境变量：

```bash
export IWENCAI_API_KEY="粘贴你自己的-Key"
python3 server.py --open
```

Windows PowerShell：

```powershell
$env:IWENCAI_API_KEY="粘贴你自己的-Key"
python server.py --open
```

请勿把 Key 放入 README、截图、Issue、源码、`.env` 或 Git 提交。如果 Key 曾经公开暴露，请立即在 SkillHub 作废/轮换。

## Excel 格式

- 文件名需包含日期，例如 `板块矩阵_2026-11-17.xls`。
- 表头第一列需包含“题材 / 指标”，后续列为题材。
- 行标签使用“首板”、“2板”、“3板”等。
- 支持短线侠导出的 HTML 格式 `.xls` 和标准 `.xlsx`。旧版二进制 `.xls` 请先另存为 `.xlsx`。

## 本地存储与隐私

- 所有复盘数据默认保存在 `data/state.json`。
- 上传仓库前不要强制添加 `data/`、Excel、截图或 `.env`。
- 备份只需复制 `data/state.json`；恢复时放回同一位置。
- 浏览器与本地服务之间使用一次性请求令牌，服务仅监听 `127.0.0.1`。

## 开发与测试

服务端和 Excel 解析仅使用 Python 标准库。前端为原生 HTML/CSS/JavaScript，长图导出内置了 `html2canvas` 发布文件及其 MIT 许可。

```bash
python3 -m unittest -v test_server.py
node --test test_engine.mjs
```

修改 `static/app.source.js` 后重新生成实际服务的前端包：

```bash
node build_app_bundle.mjs
```
